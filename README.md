# Homelab Project
This project will begin by working through Grant Collin's course on projectsecurity.io to gain an understanding of how to setup a homelab. From there the homelab may change in structure or programs, but it will maintain AD, a security server, and multiple workstations. 

I may possibly write my own malware and/or keylogger which will communicate with an external server to simulate such data capturing and exfiltration.

I am calling the initial homelab that results from following the homelab course "Version1".
